Learnova Biology — standalone browser copy

This is the browser-only HTML/CSS/JavaScript version of the supplied Learnova site.

Files:
- index.html — entry page
- app.css — styling
- app.js — application logic and interactions
- questions.json — question data
- assets/ — original question images
- Learnova-Biology-Questions-Parts-1-2-9.pdf — downloadable question PDF

Run locally:
- You can now double-click index.html and open it directly.
- For the most reliable browser behavior, serve the folder with any static server:
  python3 -m http.server 4173
  Then open http://127.0.0.1:4173

The question bank is embedded in app.js for direct file opening. The separate questions.json file is retained as a readable data copy. No Python, Node, terminal, or command prompt is required.
